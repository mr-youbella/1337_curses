[Repository](../README.md) · **Team project** · **Status: In progress**

## Current status

I am currently working on `ft_transcendence` with a team. This collection contains the [subject, version 21.2](../Subjects/ft_transcendence.subject.pdf), and this project overview. Application source code and build configuration are not included here yet, and no evaluation score is recorded.

The application idea, selected modules, technology stack, and individual contributions are not documented in this checkout. The requirements below describe the supplied subject, not a list of completed features.

## Project scope

The subject leaves the application concept to the team. Its examples include games, collaborative platforms, social applications, and productivity tools. The common foundation is a multi-user web application with a frontend, backend, and database.

| Area | Subject requirements |
| --- | --- |
| Interface | A responsive, accessible frontend using a styling solution chosen by the team. |
| Accounts | Secure email/password registration and login, with simultaneous users supported. |
| Data | A defined database schema and validation in both frontend and backend. |
| Connections | HTTPS for access to the backend. |
| Deployment | A containerized setup that starts with one command. |
| Configuration | Local credentials in an ignored `.env`, with an `.env.example` for setup. |
| Application information | Accessible Privacy Policy and Terms of Service pages. |

Additional modules extend that foundation. The subject requires at least **14 module points**, with major modules worth two points and minor modules worth one. Available areas include web features, accessibility, user management, AI, cybersecurity, gaming, DevOps, analytics, and blockchain. Selected modules and their completion will be documented alongside the implementation.

## Teamwork and documentation

This is a team project. The subject calls for documented roles, shared development, and a clear account of each member's contributions. Team members, assigned roles, architecture decisions, and implemented features will be added when those details are available in this collection.

No runnable application is included in this directory yet. Build commands, prerequisites, configuration, and usage examples will be added with the application code. The [subject PDF](../Subjects/ft_transcendence.subject.pdf) is the available reference for now.
